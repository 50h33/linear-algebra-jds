## 주요 교정

- W05-01③: det(A)=0이면 Ax=b는 b에 따라 해가 없거나 무수히 많다. 동차식 Ax=0은 반드시 해가 있고, 특이 정방행렬이면 비자명해도 있어 무수히 많다.
- W05-02②: 여인수 위치 부호는 (-1)^(i+j). 2+3이 홀수이므로 C23=-M23=-6.
- W05-06(가): 행 교환 한 번은 행렬식 부호를 바꾼다. 다른 행의 배수를 더하는 두 연산은 행렬식을 보존한다. det(A)=-det(U)=-2.
- W05-07: 제출한 A⁻¹·B⁻¹은 각각 원래 행렬의 성분별 역수와 같다. 역행렬은 이 방법으로 구하지 않는다. 제출 AB도 같은 위치 성분끼리 곱한 값이다. 행렬 곱은 앞 행렬의 행과 뒤 행렬의 열을 곱해 더한다.

$$
\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}
=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\quad(ad-bc\ne0).
$$

$$
A^{-1}=\begin{pmatrix}3&-2\\-1&1\end{pmatrix},\quad
B^{-1}=\begin{pmatrix}1&-1\\-1&3/2\end{pmatrix},\quad
AB=\begin{pmatrix}7&6\\9&8\end{pmatrix}.
$$

$$
(AB)^{-1}=B^{-1}A^{-1}=\begin{pmatrix}4&-3\\-9/2&7/2\end{pmatrix}.
$$

예를 들어 (AB)11=1×3+2×2=7이다. 답안의 나머지 상세 전개는 [W05-07 풀이](답과풀이.md#w05-07--예제-3-12)를 참고한다.

## 2026-10-20 사용자 기준 정정 및 코드 오답 해설

사용자 원문: “내가 모르겠다고 한 건 틀린 문제인거야. 미풀이가 아니라. 모르겠다고 한 것도 답 알려줘. 그리고 나서 다시 문제 내줘”

W05-06(나)의 ‘모르겠음’, W05-08의 ‘모르겠어’를 최초 오답으로 정정한다. 미풀이로 제외했던 이전 기록은 당시 판단 이력으로만 보존한다. W05-06은 이미 (가) 오류로 오답 문항에 포함되므로 중복 집계하지 않는다. 당시에는 정답 판정 4개·오답 포함 4개로 요약했으나, 종합 점검에서 01의 T/F 선택 정답과 설명 오답을 구분하여 완전 정답은 03·04·05의 3개로 바로잡았다. 재풀이에서는 02·06(가)·07 정답, 01③ 설명 재오답. 이번 코드 두 문항은 정답 제공 후 첫 재풀이 답변 대기이며 완료·정답으로 세지 않는다.

W05-06(나) 정답:

```python
diagonal_product = np.prod(np.diag(U))
det_A = (-1) ** swap_count * diagonal_product
det_check = np.linalg.det(original_A)
```

`np.diag(U)`는 2차원 U의 주대각선 성분을 꺼내고 `np.prod`는 그 값들을 곱한다. `(-1) ** swap_count`는 행 교환이 홀수 번이면 -1, 짝수 번이면 1이다. `np.linalg.det`은 행렬식을 직접 계산한다. 원문 수치로 각각 2, -2, 약 -2를 실행 확인했다. 한 행 자체를 상수배하지 않은 조건에서 이 부호 보정식을 사용한다.

W05-08 정답:

```python
A_inv = np.linalg.inv(A)
B_inv = np.linalg.inv(B)
right = B_inv @ A_inv
same = np.allclose(left, right)
```

`inv`는 역행렬 계산, `@`는 행렬 곱, `allclose`는 작은 수치 오차를 허용하는 모든 성분 비교이다. (AB)⁻¹=B⁻¹A⁻¹이므로 B의 역행렬을 먼저 놓는다. 원문 행렬에 실행하여 `same=True` 확인. 위 해설만으로 사용자 코드 작성 숙달을 인정하지 않는다.

재출제 원문은 [재풀이문제](재풀이문제.md)의 ‘추가 재풀이’에 저장한다. 두 답변을 한꺼번에 받는다.

## 2026-10-20 코드 첫 재풀이 채점 — 종료

사용자 제출:

```text
W05-06(나)

np.prod(np.diag(U))
(-1) * swap_count * diagonal_product
np.linalg.det(original_A)

W05-08

1. A_inv = np.inv(A)
2. B_inv = np.inv(B)
3. right = A@B
4. same = np.allclose(left, right)
```

W05-06(나): 일부 오답. 빈칸의 우변만 답한 형식은 인정한다. 첫째·셋째 식 정답. 둘째 식은 `(-1) ** swap_count * diagonal_product`여야 한다. `*`는 곱셈, `**`는 거듭제곱이다. 원문의 교환 횟수 1에서는 제출 식도 -2가 되지만 교환 횟수를 변수로 반영하는 일반식은 아니다. 예를 들어 교환 2회, 대각선 곱 2이면 제출 식 -4, 올바른 값 +2. 교환 0회에도 제출 식 0으로 잘못된다.

W05-08: 일부 오답. 첫째·둘째 줄 `np.inv`는 이 환경의 NumPy에 존재하지 않으며 `np.linalg.inv`로 수정해야 한다. 셋째 줄은 A@B를 구한 것이므로 역행렬의 곱이 아니다. `B_inv @ A_inv`로 수정한다. 넷째 줄 `np.allclose(left, right)`의 비교 코드는 정답이나 앞의 right가 잘못되어 원문 행렬에서는 False이다. 제출 코드를 그대로 순차 실행하면 첫 줄에서 AttributeError가 발생한다. 각 줄의 의도·오류를 별도로 채점했으며 전체가 실행됐다고 기록하지 않는다.

교정 코드:

```python
diagonal_product = np.prod(np.diag(U))
det_A = (-1) ** swap_count * diagonal_product
det_check = np.linalg.det(original_A)

A_inv = np.linalg.inv(A)
B_inv = np.linalg.inv(B)
right = B_inv @ A_inv
same = np.allclose(left, right)
```

검증: NumPy에 최상위 inv가 없음, 교환 횟수 1·2의 부호 계산, 원문 A·B에서 수정한 right가 inv(A@B)와 일치하고 A@B 자체는 일치하지 않음을 확인했다.

최초 ‘모르겠어’ 오답과 이번 해설 후 재오답 모두 보존한다. 추가 요청한 코드 재풀이 두 문항은 각 한 차례 완료. 앞선 W05-01③ 설명 재오답, W05-02②·W05-06(가)·W05-07 계산 재풀이 정답 이력 유지. 답변 대기 없음. 사용자 요청 없이 다시 출제하지 않는다. 풀이 종료를 숙달로 해석하지 않는다.

## 2026-10-20 종합 점검 정정

문제·풀이의 수학·코드는 검산 결과 그대로 정확하다. 현재 채점표는 모르겠어를 오답으로 반영하고, W05-01은 선택 정답·설명 부분 오답으로 구분했다. 기존 선택 답변의 정오답, 원문 제출, 재풀이 결과는 변경하지 않았다. 요청된 회차는 종료 상태다.
