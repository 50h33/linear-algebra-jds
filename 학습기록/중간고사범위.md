# 선형대수학1 중간고사 출제 범위

기말고사에는 중간고사 범위가 포함되지 않는다. 이 기록은 교수님의 출제 경향을 참고하기 위해 중간고사의 출제 안내, 별표 항목과 제외 범위를 보관한 것이다.

기준은 2026-10-19~20에 전달받은 교수님 안내다. 시험 후 실제 출제 여부를 대조한 기록은 없으므로 아래 내용을 실제 출제 문항 목록으로 단정하지 않는다.

## 4주차 특수한 행렬

온라인 수업으로 교수님의 구체적인 출제 범위를 전달받지 못했다. Python 코드가 나올 수 있다는 사용자 판단에 따라 주요 코드 연습을 포함한 것이며, 교수님의 확정 안내와 구분한다.

자료 기반 연습 참고 항목은 특수한 행렬, 전치·대칭, 기본 행 연산, REF·RREF, 소거법과 rank, 인접행렬, 선형결합, 대칭변환, 확대행렬이다. Python 연습은 배열 생성·인덱스·행렬 연산·대각합·행 연산 등을 NumPy로 재구성한 것이다. 당시 원자료의 프로그래밍 부분은 C·MATLAB이며 이 Python 문제를 강의 원문 코드로 취급하지 않는다.

## 6주차 수반행렬과 크래머의 규칙 및 선형결합

**교수님 출제 안내**

- 5주차 Review: `A_inverse = [row[2:] for row in augmented]`로 오른쪽 역행렬 부분 추출.
- 실습 1: `I = np.eye(3)`, `AI = np.hstack((A, I))`, 검산 안내 출력과 `print(A @ A_inverse)`.
- 실습 2: `[[1,-3,4],[2,-5,7],[0,-1,1]]`을 `np.array(..., dtype=float)`로 생성, I·AI 구성, `if np.linalg.matrix_rank(A) < A.shape[0]:` 조건.
- 실습 3: 여인수 부호와 소행렬식 계산 `C[i, j] = ((-1) ** (i + j)) * np.linalg.det(minor)`, `det_A = round(np.linalg.det(A))`, `C = cofactor_matrix(A)`, `adj_A = C.T`, `inverse_A = (1 / det_A) * adj_A`. 최초 안내에는 C·adj_A·inverse_A에 대한 `np.round(..., 10)`도 포함되어 있었다.
- 예제 3-16: 숫자를 바꾸어 출제.
- 예제 3-20: 3×3 수반행렬·역행렬 계산으로 출제하며, 이 예제의 2×2 형식은 제외.
- 실습 5: `A1 = [[b[0], A[0][1]], [b[1], A[1][1]]]`, `A2 = [[A[0][0], b[0]], [A[1][0], b[1]]]`로 열 교체. `D = determinant_2x2(A)`, `D1 = determinant_2x2(A1)`, `D2 = determinant_2x2(A2)`.

**별표 항목**

- 수반행렬의 정의와 수반행렬·역행렬의 관계 공식.

- 수반행렬로 역행렬 구하기.
- 크래머의 규칙.

**제외 안내:** 실습 6의 3×3 크래머 코드·계산. 이는 예제 3-20의 3×3 수반행렬·역행렬 계산이나 실습 5의 2×2 크래머 문제를 제외한다는 뜻이 아니다.

**연습에서만 제외한 항목:** `round`·`np.round` 반올림 보정은 사용자 요청으로 예상문제와 채점에서 제외했다. 교수님 출제 안내에서 빠졌다는 근거는 없으므로 시험 제외로 분류하지 않는다. 실습 4·7·8도 지정 연습문제에 추가하지 않았을 뿐, 시험 제외로 확인된 항목은 아니다.

## 출제 경향 참고

중간고사 출제 안내에서 참고할 문제 구성 방식은 다음과 같다.

- 정의·정리·성질을 T/F나 객관식으로 확인한다.
- 수업 자료의 예제를 그대로 내거나 숫자·행렬 크기를 바꾼다.
- 계산 과정의 빈칸을 묻거나 실습의 핵심 코드를 지정한다.
- 별표 항목과 특정 예제·실습을 구체적으로 안내한다.

이런 형식이 기말에도 적용되는지는 기말 출제 안내를 기준으로 판단한다. 중간고사 개념·예제·코드를 기말 학습 범위에 추가하지 않는다. 연습에서만 제외했던 항목은 교수님의 출제 경향을 판단하는 근거로 사용하지 않는다.

시험 후 실제 출제·미출제 사실이 확인되면 당시 안내와 구분하여 기록을 보완한다.
