### 종료 기준 — 2026-10-19 사용자 지정

사용자 원문: “앞으로 내가 말한 문제 유형을 다 다룬 후 -> 오답 재풀이 까지만 진행해줘.”

- 해당 주차에서 사용자가 알려준 출제 유형과 별표 항목을 모두 다루면 새 문제 출제를 끝낸다. 겹치는 유형은 한 문제로 함께 확인할 수 있다.
- 이어서 틀린 원문제만 한 차례 재풀이하고 그 회차를 종료한다. 5주차부터는 최신 요청에 따라 틀린 소문항을 한꺼번에 제시한다. 재풀이에서도 틀린 문제는 기록에 남기며 자동 반복하지 않는다.
- 유형 연습 도중 필요한 해설과 같은 문제의 힌트는 제공하되, 변형·추가 보충·종합 확인 문제로 자동 확장하지 않는다.
- 힌트 후 정답이나 풀이 근거 보완 사항은 기록에 남긴다. 이를 이유로 별도 문제를 계속 추가하지 않는다. 추가 연습·추가 복습은 사용자가 요청할 때만 진행한다.
- 종료 시 유형별 진행, 정오답·힌트 여부, 오답 재풀이 결과, 다음 재개 위치를 저장하고 종료 사실을 알린다. 다음 주차도 자동으로 시작하지 않는다.

2026-10-20 추가 요청: 4주차는 지정 시험 범위를 모르므로 자료에서 연습 유형을 선정하며 주요 Python 코드 문제도 포함한다. 26문제 고정 순서는 진도 파일을 따른다. 4주차 원본에는 Python 코드가 없어 수학·MATLAB 예제를 NumPy로 재구성했음을 밝힌다. 이후 주차도 Python 자료와 주요 코드를 검토 대상에 포함하며 실제 출제 유형은 주차별로 고정한다.

현재 제외 범위는 모든 주차의 C프로그래밍 내용과 2주차 1.3 선형대수학과 인공지능이다. 사용자의 명시적인 제외 지시를 자료 전체 확인 규칙보다 우선한다. 프로그래밍 실습의 수학 개념과 프로그래밍 문법을 구분하며, 알려준 시험 유형을 중심으로 출제한다.

1. 사용자가 알려준 교수님의 출제 유형을 원문 그대로 진도에 기록한다. 주차와 연결할 수 있으면 수업 자료를 근거로 연결한다. 연습 문제를 실제 시험 문제라고 단정하지 않는다.
2. 해당 주차를 공부하기 전에 `n주차` 디렉토리와 모든 하위 디렉토리의 파일을 확인한다. Git에서 제외된 PDF와 PPTX도 포함한다. PDF의 본문과 수식·그림, PPTX의 슬라이드와 노트, 노트북의 설명·코드·저장된 출력, 기타 코드를 확인한다. 파일명이나 텍스트 추출만으로 수식·그림이 불명확하면 해당 페이지나 슬라이드를 직접 확인한다.
3. 아래 자료 목록의 확인 표시는 실제 내용 검토 후에만 갱신한다. 읽을 수 없거나 확인하지 못한 부분을 기록하고, 새 파일이 있으면 목록에 추가한다. 자료 검토와 사용자의 학습 완료는 구분한다.
4. 수업 자료의 범위·표기·풀이 방식과 전달받은 유형에 맞춰 문제를 만든다. 출제 전에 해의 존재와 정답, 풀이를 검산한다. 필요한 조건을 문제에 명시한다.
5. 2~4주차는 한 번에 한 문제씩 진행했다. 5주차부터는 문제와 답·풀이를 별도 파일로 함께 저장하고 사용자의 일괄 제출을 기다린다. 문제 번호·원문과 실제 답변을 기록한다.
6. 답변을 받으면 사용자의 답을 보존하고 채점한다. 정답 여부와 핵심 이유를 설명한다. 풀이가 없으면 답만으로 오류 원인을 단정하지 않고, 맞는 다른 풀이도 인정한다. 답변이 모호하면 오답으로 확정하기 전에 확인한다.
7. 틀린 문제는 원문, 사용자 답, 정답, 풀이, 확인된 실수와 재풀이 기록을 오답노트에 남긴다. 출제 자체의 오류는 수정하고 사용자의 오답으로 세지 않는다.
8. 출제·채점·힌트 제공·재풀이 때마다 해당 기록과 현재 진도를 저장한다. 이전 기록을 지우지 않고 새 시도를 누적한다. 오답 채점 뒤 정답·해설을 제공하고 재풀이를 제시하는 현재 요청을 따른다. 정답을 미리 제공했다는 사실을 기록하고, 후속 정답을 힌트 없는 최초 정답으로 바꾸지 않는다.

## 기록 기준

2026-10-20 사용자 기준 정정: “모르겠어/모르겠음”도 오답으로 기록하고 정답·풀이 제공 후 재풀이 대상에 포함한다. 단순 무응답과 구별한다. 이전의 미풀이·오답 제외 판정은 당시 기록이며 이 최신 기준이 우선한다. 과거의 설명 후 정답·재풀이 성공 이력은 지우지 않으며 최초 모르겠어 응답은 오답 이력으로 해석한다. 기존 LA 숫자 집계는 옛 기준의 역사적 집계이며 현재 기준으로 재집계했다고 주장하지 않는다.
