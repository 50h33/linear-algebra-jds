## W06-01 · 오른쪽 블록 추출

```python
A_inverse = [
    row[2:] for row in augmented
]
```

결과는 `[[3, -4], [-2, 3]]`이다. `for row in augmented`는 각 행을 차례로 꺼낸다. `row[2:]`는 인덱스 2인 **세 번째 성분부터 끝까지** 가져온다. 앞의 두 성분은 소거를 마친 항등행렬 부분이고 뒤의 두 성분이 역행렬 부분이다. `2`는 행의 번호가 아니라 각 행에서 잘라내기 시작하는 열 인덱스다.

3×3의 3×6 중첩 리스트라면 `row[3:]`를 쓴다. 일반적으로 [Iₙ | A⁻¹]의 각 행에서 오른쪽 n개를 가져오려면 `row[n:]`이다. 왼쪽을 I로 만드는 소거가 끝났다는 조건이 필요하다.

## W06-02 · 실습 1

```python
I = np.eye(3)
AI = np.hstack((A, I))
```

`eye(3)`은 3차 단위행렬을 만든다. `hstack`은 배열을 가로로 붙인다. `(A, I)`는 붙일 두 배열을 한 묶음으로 넘기는 부분이다. [A | I]의 크기는 **(3,6)**이다.

$$
[A\mid I]=\left(\begin{array}{ccc|ccc}
1&2&3&1&0&0\\
2&5&3&0&1&0\\
1&0&8&0&0&1
\end{array}\right).
$$

검산 코드는 다음과 같다.

```python
print("\n검사: A x A^(-1)")
print(A @ A_inverse)
```

올바른 역행렬이면 결과는

$$I_3=\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}$$

이다. 실제 실수 계산에서는 아주 작은 오차가 보일 수 있다. `@`는 행렬 곱이다. 소거 후 이 실습의 역행렬은 [[-40,16,9],[13,-5,-3],[5,-2,-1]]이며, NumPy 배열에서 오른쪽 블록 추출은 `AI[:, 3:]`이다. 추출 코드 자체는 이 문항의 별도 답변 요구가 아니다.

## W06-03 · 실습 2

```python
A = np.array([
    [1, -3, 4],

], dtype=float)

I = np.eye(3)

if np.linalg.matrix_rank(A) < A.shape[0]:

else:

```

`dtype=float`는 소거 과정의 나눗셈 결과를 실수형으로 저장하게 한다. `A.shape[0]`은 **행 수 3**, `matrix_rank(A)`는 **2**다. 따라서 `2 < 3`이 참이고 “역행렬이 존재하지 않습니다.”가 출력된다.

R₂−2R₁=(0,1,-1)이고 R₃=(0,-1,1)은 그 음수다. 첫째 행과 (0,1,-1)은 독립이므로 rank=2이며, det(A)=0이다. 정방행렬의 rank가 차수보다 작으므로 역행렬이 없다. 단순히 오른쪽 블록을 꺼내는 것만으로 역행렬이 되지는 않는다. 왼쪽 블록을 항등행렬로 만들 수 있어야 한다.

## W06-04 · 수반행렬의 정의와 공식

1. **여인수행렬 C를 전치한 행렬**이 수반행렬이다.

$$\operatorname{adj}(A)=C^T,\qquad [\operatorname{adj}(A)]_{ij}=C_{ji}.$$

2. 정방행렬 A에 대해

$$A\operatorname{adj}(A)=\operatorname{adj}(A)A=\det(A)I_n.$$

역행렬 공식은

$$A^{-1}=\frac1{\det(A)}\operatorname{adj}(A)\quad\text{단, }\det(A)\ne0.$$

첫 번째 항등식은 특이행렬에서도 성립한다. 두 번째 식은 0으로 나눌 수 없으므로 det(A)≠0이 필요하다.

3. (가) **F:** 원래 A가 아니라 **여인수행렬 C**를 전치한다. (나) **F:** det(A)=0이어도 여인수와 수반행렬을 구할 수 있다. (다) **T:** det(A)Iₙ=0Iₙ=O이다.

## W06-05 · 예제 3-16 숫자 변경 풀이

각 자리의 행과 열을 지워 2×2 행렬식을 구한다.

$$
\begin{array}{lll}
M_{11}=1\cdot3-(-1)\cdot1=4,&
M_{12}=0\cdot3-(-1)\cdot2=2,&
M_{13}=0\cdot1-1\cdot2=-2,\\
M_{21}=2\cdot3-1\cdot1=5,&
M_{22}=1\cdot3-1\cdot2=1,&
M_{23}=1\cdot1-2\cdot2=-3,\\
M_{31}=2(-1)-1\cdot1=-3,&
M_{32}=1(-1)-1\cdot0=-1,&
M_{33}=1\cdot1-2\cdot0=1.
\end{array}
$$

따라서 소행렬식의 배열은

$$[M_{ij}]=\begin{pmatrix}4&2&-2\\5&1&-3\\-3&-1&1\end{pmatrix}.$$

위치 부호를 곱하면

위치 부호는 첫째 행 +,-,+, 둘째 행 -,+,-, 셋째 행 +,-,+이다.

$$C=\begin{pmatrix}4&-2&-2\\-5&1&3\\-3&1&1\end{pmatrix}.$$

마지막으로 전치한다.

$$\boxed{\operatorname{adj}(A)=\begin{pmatrix}4&-5&-3\\-2&1&1\\-2&3&1\end{pmatrix}}.$$

검산: det(A)=1·4+2·(-2)+1·(-2)=-2이고 A adj(A)=-2I₃이다. det와 역행렬은 이 문항의 추가 제출 항목이 아니다.

## W06-06 · 예제 3-17 풀이

소행렬식 아홉 개는 다음과 같다.

$$[M_{ij}]=\begin{pmatrix}-3&-6&-3\\-6&-12&-6\\-3&-6&-3\end{pmatrix}.$$

예를 들어 M₁₂=4·9−6·7=-6, M₂₂=1·9−3·7=-12이다. 각 자리에 (-1)^(i+j)를 곱하면

$$C=\begin{pmatrix}-3&6&-3\\6&-12&6\\-3&6&-3\end{pmatrix}.$$

이번 C는 대칭행렬이므로 Cᵀ=C이다. 따라서

$$\operatorname{adj}(A)=\begin{pmatrix}-3&6&-3\\6&-12&6\\-3&6&-3\end{pmatrix}.$$

모든 여인수행렬이 대칭인 것은 아니다. 반드시 전치하는 단계가 필요하고, 이 예제에서만 전치 전후 값이 같은 것이다.

첫째 행으로 전개하면

$$\det(A)=1(-3)+2(6)+3(-3)=0.$$

**역행렬은 존재하지 않는다.** 하지만 위처럼 수반행렬은 존재한다. det(A)=0이라고 adj(A)가 반드시 영행렬인 것도 아니다.

## W06-07 · 예제 3-20의 3×3 역행렬

소행렬식 배열과 여인수행렬은 다음과 같다.

$$[M_{ij}]=\begin{pmatrix}-2&-7&-18\\5&-4&2\\-7&-3&23\end{pmatrix},\qquad
C=\begin{pmatrix}-2&7&-18\\-5&-4&-2\\-7&3&23\end{pmatrix}.$$

예를 들어 M₁₂=5(-1)−1·2=-7이므로 C₁₂=7이고, M₂₃=2(-2)−(-3)·2=2이므로 C₂₃=-2이다.

첫째 행 여인수 전개로

$$\det(A)=2(-2)+(-3)(7)+1(-18)=-43.$$

전치하면

$$\operatorname{adj}(A)=\begin{pmatrix}-2&-5&-7\\7&-4&3\\-18&-2&23\end{pmatrix}.$$

따라서

$$
A^{-1}=\frac1{-43}\begin{pmatrix}-2&-5&-7\\7&-4&3\\-18&-2&23\end{pmatrix}
=\boxed{\frac1{43}\begin{pmatrix}2&5&7\\-7&4&-3\\18&2&-23\end{pmatrix}}.
$$

검산: A adj(A)=-43I₃이므로 위 역행렬을 곱하면 I₃이다. 소행렬식 → 여인수 부호 → 전치 → det(A)로 나누기의 순서로 계산한다.

## W06-08 · 실습 3 코드 정답

```python
def cofactor_matrix(matrix):
    n = matrix.shape[0]
    C = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            minor = get_minor(matrix, i, j)
            C[i, j] = ((-1) ** (i + j)) * np.linalg.det(minor)  # ①
    return C

det_A = round(np.linalg.det(A))  # ②

if det_A == 0:
    print("역행렬이 존재하지 않습니다.")
else:
    C = cofactor_matrix(A)          # ③
    adj_A = C.T                    # ④
    inverse_A = (1 / det_A) * adj_A # ⑤

    C = np.round(C, 10)                 # ⑥
    adj_A = np.round(adj_A, 10)         # ⑦
    inverse_A = np.round(inverse_A, 10) # ⑧
```

- ① `minor`는 행·열을 제거한 **배열**이고 `np.linalg.det(minor)`가 소행렬식 **값**이다. `**`는 거듭제곱이다.
- ② `round(...)`는 이 실습의 정수 행렬식을 부동소수점 근삿값에서 정수로 정리한다. 여기서는 -1이다.
- ③ 여인수행렬을 계산하는 함수를 호출한다.
- ④ 전치 대상은 원래 A가 아니라 C이다. `C.T`는 속성이므로 `C.T()`로 쓰지 않는다.
- ⑤ `(1 / det_A)`는 스칼라이므로 배열의 각 성분에 `*`로 곱한다. 행렬 곱을 하는 줄이 아니다.
- ⑥~⑧ `np.round(..., 10)`은 배열 각 성분을 소수점 아래 10자리로 반올림한다. `10`은 유효숫자 개수나 행렬 크기가 아니다.

Python의 (i,j)는 수학의 (i+1,j+1)이다. 따라서 부호는 (-1)^((i+1)+(j+1))=(-1)^(i+j+2)=(-1)^(i+j)로 같다.

이 A의 계산 결과:

$$C=\begin{pmatrix}40&-13&-5\\-16&5&2\\-9&3&1\end{pmatrix},\quad
\operatorname{adj}(A)=\begin{pmatrix}40&-16&-9\\-13&5&3\\-5&2&1\end{pmatrix},$$

$$A^{-1}=\begin{pmatrix}-40&16&9\\13&-5&-3\\5&-2&-1\end{pmatrix}.$$

**반올림의 적용 범위:** `round(det)`를 모든 실수 행렬의 가역 판정에 그대로 적용하면 안 된다. 예를 들어 det=0.2를 0으로 반올림하면 가역행렬을 특이행렬로 잘못 판단한다. 이번 문항은 강의의 정수 성분 행렬과 코드를 재현하는 조건이다. 반올림이 항상 계산 오차를 완전히 없앤다는 뜻도 아니다.

## W06-09 · 크래머의 규칙

1. **A가 정방행렬이고 det(A)≠0일 때**, A의 i번째 **열**을 b로 교체한 행렬을 Aᵢ라 하면

$$x_i=\frac{\det(A_i)}{\det(A)}.$$

행을 바꾸지 않는다. 교체하는 열 이외의 성분은 그대로 둔다.

2. 시스템의 계수행렬과 상수벡터는

$$A=\begin{pmatrix}3&-2\\-5&4\end{pmatrix},\quad b=\begin{pmatrix}6\\8\end{pmatrix}.$$

$$A_1=\begin{pmatrix}6&-2\\8&4\end{pmatrix},\qquad A_2=\begin{pmatrix}3&6\\-5&8\end{pmatrix}.$$

$$D=3·4-(-2)(-5)=2,$$
$$D_1=6·4-(-2)·8=40,\qquad D_2=3·8-6(-5)=54.$$

따라서 **x=40/2=20, y=54/2=27**이다. 대입하면 60−54=6, −100+108=8로 두 식을 만족한다.

3. **F.** det(A)=0이면 이 나눗셈 공식으로 유일한 해를 구할 수 없다. Ax=b는 **b에 따라 해가 없거나 무수히 많다**. 같은 A=diag(1,0)도 b=(1,0)ᵀ이면 해가 무수히 많고 b=(1,1)ᵀ이면 해가 없다.

## W06-11 · 선형결합과 영벡터

1. **주어진 벡터 각각에 스칼라를 곱한 뒤 더하여 얻는 벡터**가 그 벡터들의 선형결합이다. 두 벡터의 경우 ca₁+da₂ (c,d∈ℝ)이다. 선형시스템은 여러 선형방정식을 함께 만족시키는 해를 구하는 대상이며, 선형결합 그 자체와 같은 뜻은 아니다.

2. 성분끼리 더하고 스칼라를 곱한다.

$$a_1+a_2=\begin{pmatrix}3\\7\\3\end{pmatrix},\qquad
2a_1+a_2=\begin{pmatrix}5\\10\\4\end{pmatrix}.$$

3. 영벡터는 모든 성분이 0인 벡터다.

$$0=\begin{pmatrix}0\\0\\0\end{pmatrix},\qquad
a_1+0=\begin{pmatrix}2\\3\\1\end{pmatrix},\qquad
0a_1=\begin{pmatrix}0\\0\\0\end{pmatrix}.$$

영벡터와 스칼라 0은 표현을 공유하더라도 서로 다른 대상이다.

4. 행렬–벡터 곱은 열벡터의 선형결합으로 쓸 수 있다.

$$Ax=\begin{pmatrix}2&1\\3&4\\1&2\end{pmatrix}\begin{pmatrix}c\\d\end{pmatrix}
=ca_1+da_2=\begin{pmatrix}2c+d\\3c+4d\\c+2d\end{pmatrix}.$$

## W06-12 · 평면의 방정식

1. 외적을 계산한다.

$$n=a_1\times a_2=(3·2-1·4,\;1·1-2·2,\;2·4-3·1)^T=(2,-3,5)^T.$$

n은 a₁,a₂ 모두에 수직인 **법선벡터**다. 0이 아니므로 두 벡터는 평행하지 않고, 모든 선형결합은 원점을 지나는 평면을 이룬다.

2. 평면 위 p=(x,y,z)ᵀ와 법선벡터의 내적이 0이다.

$$n\cdot p=0\quad\Longrightarrow\quad\boxed{2x-3y+5z=0}.$$

3. x=2c+d, y=3c+4d, z=c+2d를 대입하면

$$2(2c+d)-3(3c+4d)+5(c+2d)=4c+2d-9c-12d+5c+10d=0.$$

모든 실수 c,d에 대해 성립한다.

4. c=d=0이면 p=0a₁+0a₂=0이므로 원점을 포함한다. 원점을 지나는 평면의 방정식이므로 우변은 0이다. 법선벡터의 부호를 바꾸거나 방정식 전체에 0이 아닌 상수를 곱한 답도 같은 평면을 나타낸다.
